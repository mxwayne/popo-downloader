## 使用边界

模拟测试通过只证明对应代码路径，不代表同事现场问题已解决。405 的服务端具体拒绝条件仍未知；要验证现场是否解决，应在 Dev 上对原失败文件重试并记录扩展诊断中的失败步骤、HTTP 状态、业务码和恢复次数。若仍为 405，再做同账号同文件的网页原生与扩展请求对照，隐藏所有 Cookie、Authorization 值和签名 URL，仅保留请求头名称、参数名称/非敏感 ID、HTTP/业务码及 Trace ID。
